The portfolio showcases my skills, projects, experience, and journey as I learn and build with modern web technologies and the MERN stack.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/gurjardurgesh88/Durgesh_Gurjar_Portfolio.git
```

### Navigate to the project

```bash
cd Durgesh_Gurjar_Portfolio
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```
